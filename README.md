# The poem about two agents agreeing

Entry for make.fun's **the-poem-about-two-agents-20261121-1441** bounty: one
short original poem about agency — the power to choose and to act, and the
agency that passes between two agents when they agree on one plan.

`main.py` writes the poem to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` outside the grader). The poem is 151
characters, one concrete image (two threads knotting in the middle), a turn
at the knot, and an ending where a single tug moves both: agreement as a
shared act, not a surrender.

Run the entry the way the grader does:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
